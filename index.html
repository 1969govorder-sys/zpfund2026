How to use Budget Desk

  1. Master data: add budget heads and schemes. Four Social Forestry ranges are provided and can be renamed.
  2. Allocation: select date, range, budget head, scheme and amount. Add separate entries for each release. Opening funds can be entered as an allocation before the reporting period with an explanatory remark.
  3. Expenditure: enter net bill amount, Income Tax, GST, Royalty, Labour Cess, purpose and Khajane-2 identifiers. Grand total is calculated as net bill amount plus all four deductions, and used as expenditure. Bill / token / UTR may be entered later by editing the record.
  4. Balance: opening balance + allocations in the selected period − expenditures in that period = closing balance. Opening includes all earlier matching entries. Each entry date decides its financial year (April–March).
  5. Reports: choose filters and a grouping. Excel contains summary and detailed sheets. Save PDF opens the browser print window: choose Save as PDF, Landscape and A4, then Save.
  6. Corrections: edit or delete from Transactions; confirmed deletions cannot be undone except by restoring a backup.

Amounts are stored in paise to avoid decimal rounding errors. Maximum per entry: ₹9,99,99,99,999.99. Allocation means funds made available; expenditure means the grand total (net bill amount plus deductions). This is an offline register, with no live connection to Khajane-2, banks or SMS.

Local login: password verification uses a salted hash. Financial data is not encrypted. There is no online password reset; keep your changed credentials safely. JSON restores data but does not change login credentials.

Older records: existing expenditure totals stay unchanged. Because old backups have no deduction breakdown, their original amount is initially placed in Net bill amount, with deductions set to zero and marked for review. Edit those entries to provide the actual split. Payee names are retained in backups and are available in the Payee Ledger. Older unnamed entries appear as Payee not entered; edit those entries to assign a name. New JSON backups require this updated webpage.

For Kannada or Hindi remarks, use your computer’s language keyboard. Remarks support up to 5,000 characters.
